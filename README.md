# Task 3 – js-school-project-BabuM
A JavaScript school project to build a responsive dynamic web application.

# 🎯 Project Goal
To design and develop a **timeline app** that shows the history of social media platforms using semantic HTML and modern CSS.  
The application also demonstrates **theme toggling**, **modal dialogs**, **dynamic data rendering with JavaScript**, and **responsive design best practices**.

# 🗺️ Roadmap

# ✅ Task 1: HTML Skeleton
- Set up the basic structure using semantic elements (`<header>`, `<main>`, `<section>`, etc.)  
- Include placeholders for timeline items and modal  
- Add logo and theme toggle button  

# 🔄 Task 2: CSS Styling
- Style the timeline layout and event cards  
- Implement responsive design (mobile, tablet, desktop)  
- Use CSS custom properties (`--accent-color`) for themes  
- Implement theme toggling (light/dark mode)  

# 🔄 Task 3: Dynamic Web Development
- Fetch events dynamically from `events.json` using vanilla JS  
- Render event markers into `#timeline`  
- Add modal dialogs to display event details  
- Implement close functionality for modals  
- Ensure clean code and best practices
