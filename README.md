# My Timeline App

## Overview
**My Timeline App** is a React + TypeScript web application that displays a timeline of popular social media platforms. This project focuses on **web accessibility**, ensuring the app is usable by all users, including those with disabilities.

---

## Features
- Interactive timeline of social media platforms with images, descriptions, and years.
- Accessible modal popup for event details.
- Keyboard navigation: Tab, Arrow keys, Enter/Space to interact.
- Focus management: focus trap inside modal and return to triggering element.
- Dark/Light theme toggle with local storage support.
- Color contrast optimized for WCAG AA compliance.

---

## Tech Stack
- **Frontend:** React, TypeScript, Vite
- **Styling:** CSS
- **Data:** Local JSON file (`events.json`)  
- **Accessibility:** ARIA roles, focus management, keyboard navigation
